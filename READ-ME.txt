ALL FILES ARE HERE IN ONE PLACE. NO SUBFOLDERS.


STEP 1 - SEE YOUR CARD RIGHT NOW
--------------------------------
Double-click:   CARD.html

That is your finished card. It works offline, with no
internet and no setup. Try every button:
   Call / WhatsApp / Email / Location
   All 6 links
   "Save Contact"  <- saves you into the phone

You can WhatsApp CARD.html to yourself and open it on
your phone too.


STEP 2 - PUT IT ONLINE (needed for the printed QR)
--------------------------------------------------
The QR needs a permanent web address, so upload these
4 files:

     index.html
     links.json
     photo.jpg
     _headers

2A. GITHUB
    1. github.com  ->  sign in (free)
    2. New repository
    3. Name:  mishthi-card
    4. Public  ->  Create repository
    5. Click "uploading an existing file"
    6. Drag in these 4 files:
          index.html
          links.json
          photo.jpg
          _headers
    7. Commit changes

2B. CLOUDFLARE PAGES
    1. dash.cloudflare.com  (free)
    2. Workers & Pages  ->  Create  ->  Pages
    3. Connect to Git  ->  pick  mishthi-card
    4. Framework preset : None
       Build command    : LEAVE EMPTY
       Output directory : /
    5. Save and Deploy
    6. Wait ~1 minute

    You get an address like:
         https://mishthi-card.pages.dev

    *** WRITE IT DOWN. THIS IS YOUR FOREVER ADDRESS. ***

    Open it on your phone. Check every link.


STEP 3 - MAKE THE QR  (only AFTER step 2)
-----------------------------------------
    1. Double-click  QR-MAKER.html
    2. Paste your real address in the box
       (with https:// and the / at the end)
    3. Size 1200,  Error correction H
    4. Download PNG  (or SVG for the printer)
    5. Send that file to your NFC card printer

    PRINT RULES:
       - Minimum 25 x 25 mm on the card
       - KEEP the white border, never crop
       - Pure black on white, never invert
       - Test-scan the sample with 2-3 phones


STEP 4 - PROGRAM THE NFC CHIP
-----------------------------
    1. Install the app  "NFC Tools"
    2. Write -> Add a record -> URL
    3. Type the SAME address as the QR
    4. Write -> hold the card to the phone
    5. Optional: Lock the tag (permanent)


CHANGING DETAILS LATER
----------------------
    1. github.com -> your mishthi-card repo
    2. Click  links.json
    3. Click the pencil icon
    4. Edit -> Commit changes
    5. Wait 30 seconds

    Done. Every printed card shows the new details.
    THE QR NEVER CHANGES.
    Only a domain change would need a reprint.

    links.json rules:
       - Every value in "double quotes"
       - Comma between items, NEVER after the last one
       - If it breaks, paste into jsonlint.com

    CARD.html       Your card, ready to open/share offline
